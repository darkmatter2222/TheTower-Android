## What was established

APK identity: `com.TechTreeGames.TheTower`, versionName **29.1.3**, versionCode **1253**, Unity
**6000.3.15f1**, IL2CPP arm64, minSdk 27 / targetSdk 36, portrait. Split set: base (187 MB) +
`config.arm64_v8a` (34 MB) + `gpdeku` + `gpdeku.config.arm64_v8a`.

Toolchain in `tools/`: apktool 3.0.3 output, jadx 1.5.6 output, Il2CppDumper (installed, **not yet
run** — no `dump.cs`). Extracted the metadata string table to `tools/gm_strings.txt` (46,810 entries)
with a PowerShell regex pass; that file is now the primary reference for confirming a system exists.

`LabTimeManager`, `LabSpeedUp`), `ModuleManager` + merge UIs (`AutoMergeUI`, `ModuleUnmergeUI`,
`ModuleRestoreAndMaxUI`), `RelicsManager`, `TechTreeManager`, `Vault/*`, `Guilds/*`, `TournamentManager`,
`DailyMissionManager`, `MilestoneManager`, `MailManager`, `LeaderboardManager`, `AutoPlayer`, `Perks`,
`CurrencyAudit`/`CurrencyPolicy`/`CurrencyTracker`, `Purchases/*`, `Nexus/NexusApiConfig`,
`ProcessDeepLinkManager` (deep link `thetower://link`).
